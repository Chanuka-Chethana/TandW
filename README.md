# Wedding Invitation Web App

A polished, mobile-first wedding invitation starter built with Next.js + React + TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Customize

Edit `app/page.tsx` for:
- Couple names
- Wedding date/time
- Venue
- Story
- Timeline
- RSVP behavior

Edit `app/globals.css` for colors, typography, spacing and visual style.

Replace the Unsplash image URLs in `app/globals.css` with local files in `/public` for production.
